# Security

SignLens holds no keys and never signs anything. What it can get wrong is
what it shows you, or what it sends where. If you find a way to make it
show a transaction as something it is not, to make it pass a request on
without the user's decision, or to make it send data it says it does not,
please report it privately.

Email **security@signlens.dev** with the steps to reproduce. You will get
an acknowledgement within three days and a fix or a plan within fourteen.
Please give us that time before publishing.

Reports about the SignLens API or the engine behind it go to the same
address.
